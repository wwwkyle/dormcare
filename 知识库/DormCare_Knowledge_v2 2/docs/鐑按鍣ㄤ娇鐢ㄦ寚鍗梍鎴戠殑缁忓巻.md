# 我收集的热水器使用指南

案例编号：CASE-HEATER-001。资料类型：我的实际经历及维修人员发来的使用说明。

## 我为什么收录

我在一次与热水器使用有关的实际经历中，收到了维修人员发来的操作视频和说明图片。我将它们作为使用指南收录，希望先帮助学生确认使用方法，避免直接把“不会使用”认定为“设备需要维修”。我没有补写故障日期、报修单号或修复结论。

## 我从视频中记录的内容

原视频约27秒。我按可见画面整理，背景语音不完整的部分不写成操作口令。

| 视频位置 | 我记录的画面 | 我的说明 |
|---|---|---|
| 约0–7秒 | 工作人员按下面板右侧电源键，随后面板显示42。 | 我记录开关位置；42只是视频显示值，不是通用推荐温度或实测水温。 |
| 约8–14秒 | 镜头展示黄色软管、黑色手柄及管道红色部件。 | 我保留位置画面，不补写部件功能、开关方向或复位方法。 |
| 约15–16秒 | 镜头移到窗户附近。 | 我不据此认定其他房间满足安装、排烟和通风要求。 |
| 约17–20秒 | 镜头展示水龙头及出水。 | 我不把“有水流”当成“水温正常”或“已修好”。 |
| 约21–27秒 | 镜头回到面板，仍显示42。 | 我保留状态用于核对，不据此排除全部故障。 |

我将原视频放在`assets/heater_case_01/热水器操作视频.mp4`。解压后打开`热水器使用指南.html`可以查看视频、图片和关键画面。

## 我保留的图片原话

> 黄色是燃气的开关，横着是打开工作状态。

我只把这句话用于原图红圈标注的对应阀门。我没有确认图片与视频中的阀门是同一处，也不将颜色和照片横竖推广到其他燃气设施。图中的燃气表型号不等于热水器型号。

我先请工作人员确认实际设备和允许的正常操作范围。自闭、报警或不明原因关断时，我不指导学生复位、强开、旁路或反复点火。

## 我安排的使用路径

1. 我先区分不了解操作、不出热水、报错、异常气味或报警。
2. 没有异常气味或报警时，我先确认装置与资料匹配，再提供对应指南。
3. 我要求具体阀门方向说明经过可信的装置绑定；没有绑定时不直接给开阀结论。
4. 使用后仍异常、无法确认或仍希望报修时，我保留报修入口，不自动撤单或拒单。

## 我保留的燃气异常处理边界

我参考[深圳市住房和建设局的处置提醒](https://www.sz.gov.cn/hdjl/ywzsk/jsj/rqjg/content/post_10933921.html)：燃气味、疑似泄漏和报警时，停止使用并远离现场，不开关电器、不插拔插头、不反复点火、不在现场打电话。能安全做到时关闭气源并开窗；不能安全操作时先撤离，到室外安全处联系物业和燃气抢险人员。我保存的业务联系人不替代燃气抢险服务。
